12 / Security

אבטחה במספר שכבות

זהות

bcrypt, JWT ל־15 דקות ו־refresh rotation.

הרשאות

role, self ו־participant בכל פעולה.

קלט ו־HTTP

Zod, Helmet ו־CORS מוגבל.

סודות

AES‑256‑GCM ו־HMAC‑SHA‑256.

Session

  • Access token בזיכרון בלבד
  • Refresh token בעוגיית HttpOnly
  • במסד נשמר hash בלבד

Google OAuth

  • state חד־פעמי עם TTL
  • התאמת כתובת Gmail לפרופיל
  • scope מצומצם ל־gmail.send
